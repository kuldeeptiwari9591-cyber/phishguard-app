## 📌 Overview

**PhishGuard** is an instant link-analysis tool designed to catch malicious websites before you interact with them. By combining an XGBoost machine learning model trained on **800,000+ real-world URLs** with real-time forensic security checks, PhishGuard delivers an accurate risk verdict in under 3 seconds.

No browser extensions, installations, or mandatory signups are required.

---

## ⚙️ How It Works Under the Hood

PhishGuard doesn't rely solely on static blocklists that miss brand-new attacks. Every URL undergoes a multi-layered analysis:

1. **Machine Learning Model:** Analyzes URL structures, character entropy, typosquatting patterns, and suspicious path variations using 24 isolated feature sets.
2. **Forensic Security Checks (55+ Rules):**
   * Domain age & WHOIS lookup
   * SSL certificate status and expiration verification
   * Brand impersonation and homograph attack detection
   * SPF & DMARC record checks
3. **Instant Verdict Generation:** Combines signals into a clear **Safe**, **Suspicious**, or **Critical Risk** classification along with a breakdown of flagged indicators.

## 🚀 Getting Started

1. Visit **[phishguard.co.in](https://phishguard.co.in)**
2. Paste any suspicious link from an email, SMS, or DM into the scanner.
3. Click **Scan Now** to review the risk score and detailed threat analysis.
